# AspProjects

A collection of ASP.NET projects showcasing backend development with C#, demonstrating best practices in web application architecture, database design, and enterprise patterns.

## 🚀 About

This repository contains various ASP.NET projects built to explore and demonstrate:
- ASP.NET Core architecture patterns
- Entity Framework Core integration
- RESTful API design
- Database optimization
- Enterprise application structure

## 🛠️ Tech Stack

- **Language:** C#
- **Framework:** ASP.NET / ASP.NET Core
- **Database:** SQL Server / Entity Framework Core
- **Architecture:** MVC / Clean Architecture patterns

## 📁 Projects Included

Each project folder demonstrates different aspects of ASP.NET development:
- MVC applications
- Web API implementations
- Data access patterns
- Business logic layers

## 🎯 Key Features

- Clean code principles
- Separation of concerns
- Dependency injection
- Database migrations
- API endpoints

## 📦 Getting Started

### Prerequisites
- .NET 6.0+ SDK
- Visual Studio 2022 or VS Code
- SQL Server (for database projects)

### Installation

```bash
git clone https://github.com/rdgaz/AspProjects.git
cd AspProjects
dotnet restore
dotnet build
```

### Running a Project

```bash
cd [ProjectName]
dotnet run
```
